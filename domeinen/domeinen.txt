# =====================================================================
#  DOMEINNAMEN TE KOOP
#  Elk domein begint met de naam tussen [haken], gevolgd door regels
#  in de vorm  sleutel: waarde
#
#  naam       Merknaam die op het nep-websiteje staat
#  slogan     Kopregel op het websiteje
#  tekst      Verkooptekst naast de tegel (mag over meerdere regels)
#  sjabloon   Hoe het websiteje eruitziet (zie lijst hieronder)
#  kleur      Hoofdkleur van het websiteje, als #hexcode
#  afbeelding (optioneel) eigen screenshot, bv. img/servicetag.png
#             Die vervangt dan het sjabloon.
#  tonen      nee = domein staat niet op de pagina
#  verwant    (optioneel) andere domeinnamen die erbij horen, met een
#             komma ertussen, bv.  verwant: taqqer.com, taqqer.nl
#             Ze verschijnen dan bij "Ook beschikbaar" en staan
#             vooraan in de suggesties. Dezelfde naam met een andere
#             extensie wordt al automatisch gekoppeld, dus die hoeft
#             hier niet bij. Eén keer noemen is genoeg: de koppeling
#             werkt aan beide kanten.
#
#  TWEE TALEN
#  Zet -en achter een sleutel voor de Engelse versie:
#    naam-en, slogan-en, tekst-en
#  Ontbreekt de Engelse regel, dan gebruikt de pagina het Nederlands.
#  Een slogan die al Engels is (bv. "Tag it. Track it. Done.") hoeft
#  dus geen slogan-en.
#  De vaste teksten van de pagina zelf (knoppen, labels, koppen) staan
#  in index.html, bij TEKSTEN bovenin het script.
#
#  Sjablonen:
#  saas        Softwaredienst met dashboard
#  app         App-landingspagina met telefoon
#  tech        Donkere pagina met printplaat en chip
#  bureau      Rustig advies- of innovatiebureau
#  slaap       Nachthemel met maan en artikelen
#  horloges    Webwinkel met horloges
#  kaart       Landkaart met een locatiepin
#  persoonlijk Persoonlijke of familiepagina
#  game        Game of evenement
#
#  Regels die met # beginnen worden genegeerd.
# =====================================================================
